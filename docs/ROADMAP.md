# FORGE Roadmap

## Batch 1 — Foundation
Repository, FastAPI platform API, tests, documentation.

## Batch 2 — CI/CD
Python service template, Docker, GitHub Actions, GHCR, quality gates.

## Batch 3 — Kubernetes
kind, namespaces, Helm, probes, resource limits, RBAC.

## Batch 4 — GitOps
Argo CD, automated synchronization, staging promotion, rollback.

## Batch 5 — Self-Service
Backstage, software catalog, golden paths, environment and deployment requests.

## Batch 6 — DevSecOps
Trivy, Gitleaks, SBOM, Cosign, Kyverno, audit events.

## Batch 7 — Observability and SRE
OpenTelemetry, Prometheus, Grafana, Loki, Tempo, alerts, SLOs.

## Batch 8 — Resilience and Governance
Progressive delivery, backup, restore, load tests, failure tests,
resource quotas, and cost governance.

## Completion Evidence
Passing CI, security reports, reproducible deployments, working
self-service operations, monitoring, tested rollback, and tested recovery.
